# Игра Реверси

![Swift Version](https://img.shields.io/badge/Swift-5.0+-orange.svg)
![Platform](https://img.shields.io/badge/Platform-iOS-lightgrey.svg)

Классическая настольная игра Reversi с современным дизайном и интеллектуальным ИИ. Стратегическая игра для двух игроков на поле 8x8, где цель — захватить больше всего фишек противника.

## Возможности

- Система подсчета очков и рекордов

## Требования
- iOS 13.0+
- Swift 5.0+
- Xcode 12.0+

### Через Swift Package Manager
1. В Xcode: File → Add Packages
2. Вставьте URL репозитория:
```
https://github.com/pomcheeek/Reversi-Game-with-AI.git
```
3. Выберите нужную версию
4. Нажмите "Add Package"

### Вручную
1. Скачайте или клонируйте проект
2. Откройте `ReversiAI.xcodeproj` в Xcode
3. Нажмите ▶ для запуска
